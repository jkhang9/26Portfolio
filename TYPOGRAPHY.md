# Typography

- Geist Regular: body, UI, large headings and display numerals.
- Crimson Pro Regular: upright editorial serif copy, capped at 24px.
- Commit Mono Regular: captions, tags and metadata.
- Newsreader Regular: comparison alternative at /type-comparison.html and /?serif=newsreader.

No italics. Self-hosted WOFF2 files with bundled licenses. Default site serif stays Crimson Pro.
